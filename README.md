# 🤖 LLM – Detect AI Generated Text

A Machine Learning / Deep Learning project to **detect whether a given text is written by a human or generated by a Large Language Model (LLM)** such as ChatGPT.

This project is based on the **Kaggle competition: LLM – Detect AI Generated Text** and focuses on **NLP, text preprocessing, and model evaluation**.

---

## 📌 Problem Statement

With the rapid growth of Large Language Models, it has become difficult to distinguish between **human-written text and AI-generated content**.  
This project aims to build a **robust classifier** that can accurately detect AI-generated text.

---

## 🧠 Approach

- Text preprocessing & cleaning  
- Feature extraction using **TF-IDF**
- Machine Learning models:
  - Logistic Regression
  - Random Forest
  - Gradient Boosting
- Model evaluation using **ROC-AUC score**
- Ensemble techniques for performance improvement

---

## 📂 Dataset

- Provided by **Kaggle**
- Includes:
  - Human-written essays
  - AI-generated essays
- Multiple prompts used to avoid bias

🔗 Kaggle Competition:  
https://www.kaggle.com/competitions/llm-detect-ai-generated-text

---

## 🛠 Tech Stack

- **Python**
- **Pandas, NumPy**
- **Scikit-learn**
- **TF-IDF Vectorizer**
- **Kaggle Notebook**

---

## 📊 Evaluation Metric

- **ROC-AUC Score**
- Chosen due to class imbalance and probabilistic output requirements
